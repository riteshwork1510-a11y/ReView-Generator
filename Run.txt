How to Run the AI Review Generator Project
==========================================

This project consists of two separate services: a Next.js Frontend and a FastAPI Python Backend. You will need two separate terminal windows to run both simultaneously.

---

### 1. Backend Setup & Run (Terminal 1)

1. Open your terminal and navigate to the backend folder:
   cd backend

2. Set up the Python virtual environment (only needed the first time):
   python -m venv venv

3. Activate the virtual environment:
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate

4. Install the required dependencies:
   pip install -r requirements.txt

5. Configure Environment Variables:
   - Copy `.env.example` to a new file named `.env` inside the `backend` folder.
   - Edit the `.env` file and provide your actual MongoDB connection string:
     MONGODB_URI=your_mongodb_connection_string
     MONGODB_DATABASE=ai_review_generator
     FRONTEND_ORIGIN=http://localhost:3000

6. Start the Backend Server:
   uvicorn app.main:app --reload --port 8000

The backend API will now be accessible at http://localhost:8000.

---

### 2. Frontend Setup & Run (Terminal 2)

1. Open a new terminal and navigate to the frontend folder:
   cd frontend

2. Install the required Node.js dependencies:
   npm install

3. Configure Environment Variables:
   - Copy `.env.example` to a new file named `.env.local` inside the `frontend` folder.
   - Edit the `.env.local` file and ensure it points to the backend:
     NEXT_PUBLIC_API_BASE_URL=http://localhost:8000

4. Start the Frontend Development Server:
   npm run dev

The frontend web app will now be accessible at http://localhost:3000.

---

### Quick Testing
Open http://localhost:3000 in your browser to verify both the frontend and backend are running and communicating correctly.
